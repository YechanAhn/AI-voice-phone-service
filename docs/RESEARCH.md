# Research: AI 음성 식당 예약 서비스 기술 리서치

## 1. STT (Speech-to-Text) - 한국어 음성 인식

### 벤치마크 비교 (한국어 CER - Character Error Rate)

| 제공업체 | 평균 CER (%) | 스트리밍 | 비고 |
|---------|-------------|---------|------|
| **Return Zero (RTZR)** | 5.9~6.8 | Yes (gRPC/WS) | 한국어 최고 정확도 |
| **RTZR Whisper (fine-tuned)** | 6.6~7.7 | Yes | Whisper 한국어 튜닝 |
| **Naver CLOVA Speech** | 7.5~8.1 | Yes | 네이버 자체 한국어 엔진 |
| **AWS Transcribe** | 8.9~11.1 | Yes | 범용 |
| **OpenAI Whisper (vanilla)** | 10.2~11.4 | No (batch) | 오픈소스, self-host 가능 |
| **Google STT v2** | 11.5~11.6 | Yes | 한국어 약함 |
| **Deepgram Nova-2** | 21~23.5 | Yes | 한국어 미지원 수준 |

### 추천: Return Zero (RTZR)
- 경쟁사 대비 35~46% 낮은 에러율
- 전화 통화에 최적화된 CALL 모드 지원
- 키워드 부스팅 (예약, 취소, 변경 등 도메인 용어)
- LINEAR16, FLAC, MULAW, ALAW, AMR, OGG_OPUS 포맷 지원
- 신한은행 AI 콜센터에서 실제 운영 중

### 차선: Naver CLOVA Speech
- 네이버 검색/음성 데이터 기반 한국어 네이티브 엔진
- 최근 실시간 스트리밍 지원 추가
- 네이버 클라우드 생태계 내 통합 용이
- 한국어, 영어, 일본어, 중국어(간체) 지원

## 4. 한국 전화망 연결 방법

### SIP Trunk 제공업체

| 제공업체 | 한국 번호 | 가격 | LiveKit 연동 | 비고 |
|---------|----------|------|-------------|------|
| **Telnyx** | 070 (VoIP) | $1/월~ | 공식 가이드 있음 | 추천 |
| **AVOXI** | 070/080 | $19.99/월~ | 수동 설정 | 홍콩 DC (저지연) |
| **BICS** | 070/1670/080 | 기업용 | 수동 설정 | 엔터프라이즈 |
| **Twilio** | 제한적 | - | 공식 지원 | 한국 번호 취득 어려움 |

### 한국 전화번호 종류

| 번호 대역 | 유형 | 용도 | SIP 가용성 |
|----------|------|------|-----------|
| **070** | VoIP | AI 전화 서비스 최적 | Telnyx/AVOXI/BICS 가능 |
| **02** | 서울 지역번호 | 사업장 현지 존재감 | 사업자등록 필요 |
| **1588** | 전국 대표번호 | 고객센터 | 한국 통신사 계약 필요 |
| **080** | 수신자 부담 | 무료 수신 | 일부 해외업체 가능 |

### 추천: Telnyx + 070 번호
- LiveKit 공식 연동 가이드 존재
- 한국 070 DID 번호 제공
- 필요 서류: 사업자등록증, 신분증, 주소 증빙(3개월 이내), 신청서
- SIP 인증: Credentials / IP 주소 / FQDN 방식

### 규제 사항
- **부가통신사업(VATS)** 등록으로 분류 가능 (SIP trunk 위의 AI 서비스)
  - 자본금 1억원 초과 시 과기정통부 신고 필요
  - 외국인 소유 제한 없음
- 발신번호 표시 의무 (유효한 070 번호 등록 필요)
- AI 기본법 (2024.12 제정, 2026.01 시행) 준수 필요
- PIPA (개인정보보호법) 준수 - 통화 녹음 시 동의 필요

## 5. 네이버 예약 연동

### 현실: 공개 API 없음
- 네이버 예약은 **파트너 전용 비공개 API**
- 제휴 신청 후 승인 시에만 API 문서 제공
- 제휴 신청: https://www.navercorp.com/naver/proposalView
- 문의 전화: 1644-5690

### 제휴 경로
1. 네이버 스마트플레이스에 식당 등록
2. 예약 서비스 설정 (일반형 6번, 인원(명) 단위)
3. 네이버 제휴 포탈에서 파트너십 제안 제출
4. 승인 후 비공개 REST API 문서 수령

### 알려진 API 동작 (제3자 연동 사례 기반)
- 양방향 동기화 (~60초 딜레이)
- 상태 흐름: 접수 → 확정 → 완료/취소
- 완료/취소 상태는 변경 불가
- 재고 단위: 인원(명) 필수 (건(건) 불가)
- 슬롯 간격: 30분 또는 1시간

### 대안: 캐치테이블 (CatchTable) 경유
- 한국 1위 식당 예약 플랫폼 (350만+ 사용자, 10,000+ 식당)
- **이미 네이버 예약과 동기화 기능 보유**
- B2B 포탈: https://biz.catchtable.co.kr/
- 연락: service@catchtable.co.kr / 1800-5895
- 캐치테이블과 제휴 → 캐치테이블이 네이버 동기화 처리

### 실용적 접근법
1. **자체 예약 DB 구축** (PostgreSQL) - 전화 예약의 source of truth
2. **캐치테이블 B2B 제휴** - 네이버 동기화 미들웨어로 활용
3. **네이버 직접 제휴 병행** - 장기적으로 직접 연동
4. **제공업체 무관 sync 레이어** 설계 - 향후 테이블링, 포잉 등 추가 가능

## 7. 추천 아키텍처 Tier

### Tier 1: 최고 한국어 품질 (비용 높음)
- STT: Return Zero RTZR
- LLM: HyperCLOVA X + GPT-4o (function calling)
- TTS: Naver CLOVA Voice
- 프레임워크: LiveKit + Pipecat
- 예상 응답시간: 500~900ms

### Tier 2: 균형 (품질 + 유연성) — 추천
- STT: Naver CLOVA Speech
- LLM: GPT-4o (한국어 시스템 프롬프트)
- TTS: ElevenLabs Flash v2.5
- 프레임워크: LiveKit Agents
- 예상 응답시간: 400~700ms

### Tier 3: 가장 빠른 구현
- 올인원: OpenAI Realtime API (gpt-realtime)
- 프레임워크: LiveKit SIP만
- 예상 응답시간: ~250ms
- 트레이드오프: 한국어 품질 미검증, 비용 높음

### Tier 4: 예산/오픈소스

- LLM: Qwen 3 (self-hosted)
- TTS: Kokoro-82M (한국어 지원)
- 프레임워크: Pipecat
- 예상 응답시간: 800~1200ms
