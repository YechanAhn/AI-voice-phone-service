# GTM 전략: AI 음성 식당 예약 서비스

## 1. Executive Summary

### 제품 한 줄 정의
> **식당 전화를 AI가 사람처럼 자연스럽게 받아 예약을 처리하고, 네이버/캐치테이블과 실시간 연동하는 SaaS**

### 핵심 가치 제안
| 대상 | Pain Point | 우리의 솔루션 |
|------|-----------|-------------|
| **식당 사장님** | 바쁜 시간에 전화 못 받아서 예약 놓침 | 24/7 AI가 전화 받아 예약 처리 |
| **홀 직원** | 전화 응대에 시간 빼앗겨 서비스 질 저하 | 전화 업무 제로화, 서비스에 집중 |
| **손님** | 전화 연결 안 되거나 오래 기다림 | 즉시 연결, 대기 없음 |

## 2. 시장 분석

### 2-1. TAM / SAM / SOM

```
TAM (Total Addressable Market)
├─ 한국 외식업체 수: ~77만 개 (2024 통계청)
├─ 전화 예약이 발생하는 업체: ~30만 개 (추정)
└─ 연간 시장 규모: 30만 × 월 5만원 × 12 = 1.8조 원

SAM (Serviceable Available Market)
├─ 예약 중심 업종: 한식/일식/양식/중식 중상위 + 카페
├─ 월 매출 3,000만 원 이상, 직원 3명 이상
├─ 대상 업체: ~8만 개
└─ 연간 시장 규모: 8만 × 월 7만원 × 12 = 6,720억 원

SOM (Serviceable Obtainable Market) — 3년 목표
├─ 1차 타깃: 수도권 예약 중심 식당
├─ 목표 고객: 2,000~5,000개
└─ 연간 매출 목표: 5,000 × 월 7만원 × 12 = 42억 원
```

### 2-2. 시장 트렌드

| 트렌드 | 영향 |
|--------|------|
| **인건비 상승** (2025 최저임금 10,030원) | 전화 응대 인력 비용 부담 증가 |
| **1인가구 증가** → 예약 문화 확산 | 예약 건수 자체가 늘고 있음 |
| **네이버 예약 일상화** | 온라인 예약 인프라 성숙, 연동 가치 증가 |
| **AI 수용도 상승** | ChatGPT 이후 AI 서비스 거부감 급감 |
| **노쇼 문제 심화** | 체계적 예약 관리 니즈 증가 |

### 2-3. 경쟁 환경

| 경쟁사/대안 | 유형 | 강점 | 약점 |
|------------|------|------|------|
| **네이버 예약** | 온라인 예약 | 트래픽, 인지도 | 전화 예약 불가 |
| **캐치테이블** | 예약 플랫폼 | 앱 사용자 350만 | 전화 예약 불가, 수수료 |
| **테이블매니저** | 예약 관리 | POS 연동 | AI 음성 없음 |
| **ARS/IVR 솔루션** | 자동 응답 | 저렴 | 로봇 음성, 경험 최악 |
| **콜센터 외주** | 인력 기반 | 자연스러움 | 비싸고 확장 어려움 |
| **우리 서비스** | AI 음성 + 플랫폼 연동 | 자연스러운 AI + 실시간 동기화 | 신규 서비스, 인지도 없음 |

### 2-4. 경쟁 우위 (Moat)

```
1. 한국어 STT 정확도 1위 (Return Zero: CER 5.9%)
   → AWS 대비 35~46% 높은 정확도
   → 예약 시 이름/날짜/시간 인식이 핵심, 정확도가 곧 품질

2. 자연스러운 한국어 음성 (CLOVA Voice nara_call)
   → 콜센터 전용 음성, 존댓말 자연스러움
   → ARS/IVR과 차원이 다른 경험

3. 네이버+캐치테이블 양방향 실시간 연동
   → 전화 예약이 네이버에 즉시 반영
   → 온라인 예약이 AI에 즉시 반영
   → 더블부킹 방지

4. Function Calling 기반 자동화
   → LLM이 예약 CRUD를 직접 실행
   → 별도 시나리오 설계/관리 불필요
```

## 3. 고객 세그먼트 & 페르소나

### 3-1. 1차 타깃: 예약 중심 중상위 식당

```
페르소나: 김사장 (45세, 한식당 대표)
├─ 식당 규모: 60석, 직원 5명
├─ 월 매출: 5,000만 원
├─ 월 전화 예약: 200~300건
├─ Pain: 점심/저녁 피크에 전화 놓침 (체감 30%)
├─ Pain: 직원이 전화 받느라 홀 서비스 저하
├─ Pain: 네이버 예약과 전화 예약 수기 대조
├─ Budget: 월 5~10만 원 (직원 인건비 대비 저렴하면 OK)
└─ Decision: 본인이 결정, 1주일 내 의사결정
```

### 3-2. 2차 타깃: 프랜차이즈 본사

```
페르소나: 이본부장 (38세, 프랜차이즈 운영본부장)
├─ 매장 수: 30~100개
├─ Pain: 매장별 전화 응대 품질 편차
├─ Pain: 본사 차원 예약 데이터 통합 어려움
├─ Pain: 가맹점주 인건비 불만
├─ Budget: 매장당 월 3~5만 원 (볼륨 디스카운트)
└─ Decision: 운영본부 → 대표이사 승인 (1~3개월)
```

### 3-3. 3차 타깃: 예약 플랫폼 B2B

```
파트너: 캐치테이블, 테이블매니저 등
├─ Pain: 전화 예약 채널 커버 불가
├─ Value: AI 전화를 부가 서비스로 제공
├─ Model: 화이트라벨 또는 API 연동
└─ Decision: CTO/CPO 레벨 (2~6개월)
```

## 6. 런칭 로드맵

### Phase 0: Pre-Launch (M-3 ~ M0)

```
목표: 제품 검증 + 초기 레퍼런스 10곳

[ ] 베타 테스터 모집 (무료, 10개 식당)
    ├─ 채널: 지인 네트워크, 요식업 커뮤니티
    ├─ 조건: 수도권, 월 예약 100건+, 네이버 예약 사용
    └─ 인센티브: 6개월 무료 + 피드백 시 추가 3개월

[ ] 기술 안정화
    ├─ 베타 식당 실제 트래픽으로 STT/TTS 품질 검증
    ├─ 엣지 케이스 수집 (사투리, 시끄러운 환경, 다인 통화)
    ├─ 평균 응답 시간 < 1초 달성
    └─ 99.5% 가용성 달성

[ ] 법규 준비
    ├─ 부가통신사업 신고
    ├─ 개인정보처리방침 작성 (통화 데이터)
    ├─ AI 기본법 준수 (2026.01 시행)
```

## 7. 핵심 KPI & 마일스톤

### 7-1. North Star Metric

> **월간 AI 처리 예약 건수 (Monthly AI-Processed Reservations)**

이 지표가 올라가면 고객 가치(식당 매출)도 올라가고, 우리 매출(종량제)도 올라감.

### 7-2. 단계별 KPI

| 단계 | 기간 | 목표 고객 수 | MRR | AI 처리 예약/월 | 핵심 KPI |
|------|------|------------|-----|----------------|---------|
| Pre-Launch | M-3~M0 | 10 (무료) | 0 | 500 | 예약 정확도 95%+ |
| Soft Launch | M1~M3 | 50 | 300만 | 5,000 | 전환율 30%+, 이탈률 <5% |
| Growth | M4~M12 | 500 | 3,000만 | 60,000 | CAC <15만, LTV/CAC >3 |
| Scale | M13~M24 | 3,000 | 1.5억 | 400,000 | 흑자 전환, NRR >120% |

### 7-3. Unit Economics 목표

```
Average Revenue Per Account (ARPA):
├─ Starter: 39,000원 + 초과 ~10,000원 = ~50,000원/월
├─ Standard: 79,000원 + 초과 ~15,000원 = ~95,000원/월
├─ 가중 평균: ~70,000원/월
└─ 연간 LTV: 70,000 × 12 × (1/이탈률) = 70,000 × 12 × 20 = 16,800,000원

Customer Acquisition Cost (CAC):
├─ 온라인 (커뮤니티, SEO): ~50,000원
├─ 파트너 (캐치테이블, 식봄): ~30,000원
├─ 현장 영업: ~150,000원
├─ 가중 평균 목표: < 100,000원
└─ LTV/CAC: 168 (매우 건강)

Gross Margin:
├─ 통화 원가 (STT + LLM + TTS + 전화)
│  ├─ STT (RTZR): ~50원/분
│  ├─ LLM (GPT-4o): ~30원/건 (평균 500 토큰)
│  ├─ TTS (CLOVA): ~10원/건 (무료 티어 이후)
│  ├─ 전화 (Telnyx): ~20원/분
│  └─ 인프라 (서버): ~10원/건
│  총 원가: ~120원/건 (평균 통화 2분)
│
├─ Starter 기준:
│  ├─ 수익: 39,000원/월
│  ├─ 원가: 100건 × 120원 = 12,000원
│  └─ Gross Margin: 69% ✓
│
└─ Standard 기준:
   ├─ 수익: 79,000원/월
   ├─ 원가: 300건 × 120원 = 36,000원
   └─ Gross Margin: 54% ✓
```
